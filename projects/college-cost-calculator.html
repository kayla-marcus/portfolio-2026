College Cost Calculator

Project 3 / 6

Project Overview

This college cost calculator started as a functional tool to help students and their families estimate the overall cost of attending Ridgewater College. However, the tool felt too complex. It created confusion and friction for users due to its structure and visual design.

✨ Key Achievements

  • Redesigned results page for clarity and focus
  • Strengthened visual hierarchy and call-to-action clarity
  • Enhanced interactions and fixed key functionality issues

While the tool technically worked, the experience itself needed refinement to better guide users through complex financial inputs and data-heavy results. The tool was originally created in March 2024; however, after revisting the tool, it became clear that the UX needed stronger structure, and more intentional visual guidance. Read more ↓

Introduction to the Problem.

Students and families using this tool need to feel supported. The original design lacked clear guidance and structure, leading to uncertainty and frustration.

The landing page felt underwhelming, like a simple form without any real value proposition. If the user does not feel compelled to use the tool, they may abandon it before even attemping to complete the first step.

The lifeless tone of the tool was a big problem, so I leaned into modern web design principles to create a more engaging and user-friendly experience. This included increased border radius, improved hierarchy and data grouping, and clearer call-to-actions.

Improving the First Impression.

The original landing page felt flat and uninviting, with large blocks of text and an unclear call-to-action that created a questionable first impression and made the tool feel more like a form than a helpful guide.

The redesign focused on improving clarity and motivation to start. 1A blurred campus image was added as the background with a dark overlay to create depth and context, immediately grounding the user in the college experience. 2The main heading was rewritten as a direct call to action, making it clear what the tool does and why it matters.

These changes improved hierarchy and 3made the entry point feel more intuitive and engaging. It transforms a boring and possibly stressful experience into a more supportive one, setting the tone for the entire tool.

2 / 6

Subtle Guidance Through the Form.

The original multi-step form used progressive disclosure but lacked clear navigation cues, making it harder for users to understand their progress.

Redesigning the step navigation to include a highlighted active step helps users stay oriented while moving through different sections of the calculator. It is a small but impactful change for encouraging users to complete all steps.

These improvements made the form feel more conversational and less like a static questionnaire. JavaScript-powered interactions and progressive disclosure allows users to only focus on what is relveant to their sitation, simplifying what could be a long, complex form into a quick, easy, and genuinely enjoyable experience.

3 / 6

Making Data-Heavy Content Accessible.

The original results page displayed all cost data in a flat layout with minimal structure, making it difficult to quickly interpret key financial information. Charts and values competed for attention without a clear hierarchy.

The redesign introduced 1a centered container card with the campus background to create focus and separation from the rest of the interface. 2Each chart was given a clear title and description to help users understand what they were viewing, improving comprehension and scanability.

Visual hierarchy was strengthened by emphasizing what really matters to the user—the key dollar values—and reorganizing layout spacing. The download PDF button was styled as a primary action in the brand color, and a “Start Again” option was added to improve usability and reduce friction when restarting the calculator.

4 / 6

Technical Implementation & Responsiveness.

The calculator was built using HTML, CSS, and JavaScript for calculations and interactions. Multiple scripts handled form navigation, conditional logic, and storing/retrieving values for the results page.

Responsive design was implemented using media queries to ensure the tool worked across desktops, tablets, and mobile devices. Layout adjustments were made for smaller screens, including vertical stacking of results and resizing cards to maintain readability on the background image.

Cross-browser testing helped confirm functionality in modern browsers, with additional attention given to edge cases in mobile environments. This process highlighted how small compatibility issues can impact usability and reinforced the importance of testing across devices during development.

5 / 6

Outcome & Reflection.

This project evolved from a simple functional calculator into a more intentional user experience focused on clarity, guidance, and usability. The redesign significantly improved how users move through the tool and understand their results, especially through better visual hierarchy and structured interactions.

It also strengthened both my design and development skills by requiring iteration, problem-solving, and careful attention to user flow. The final result is a more polished, user-centered tool that better reflects how design and code work together to support real decision-making.
