Purpose.

The quarterly software release email template was created for Vivacity Tech PBC to keep customers informed about new updates to the Dream™ Asset Management software. The goal was to design a visually cohesive and user-friendly format that highlighted key features and improvements in a clear, accessible way. By creating a consistent structure, the template helps customers quickly understand what’s new and how the updates enhance their user experience.

Beyond simply announcing updates, the project aimed to strengthen the company’s brand presence through every customer interaction. The design needed to feel professional and trustworthy, while also reflecting Vivacity’s modern, tech-forward identity.

Process & Collaboration.

Using Figma, Adobe Illustrator, and Photoshop, I designed the layout, wrote the copy, and developed supporting assets in line with Vivacity’s brand guidelines. Since I was part of the software development team as the web designer, I already understood the new features being released and could translate technical updates into clear, customer-friendly language. When details were uncertain, I worked directly with the lead developers to ensure accuracy and relevance.

I collaborated closely with the graphic designer, who provided the header image and valuable design feedback that helped refine the final layout. Together, we achieved a clean, modern design that effectively balanced aesthetics and functionality.

Project Results.

This project demonstrated how integrating graphic design, web design, and development knowledge can bridge communication between creative and technical teams and result in more impactful, polished deliverables for tech-based companies.
